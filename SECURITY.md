# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 2.x     | Yes       |
| 1.x     | Best effort |

## Reporting a vulnerability

carrycut is an offline local CLI (no network at runtime). Still, if you find a security issue (e.g. unsafe path handling, unexpected file reads outside intended skill/session roots), please report it responsibly.

1. Open a private GitHub Security Advisory on [YOUR_GITHUB_USER/carrycut](https://github.com/YOUR_GITHUB_USER/carrycut) if available, **or**
2. Email the maintainers via the contact listed on the GitHub profile / npm package page.

Please include:

- Description of the issue
- Steps to reproduce
- Affected version / commit
- Any suggested fix

Do **not** file a public issue for unfixed vulnerabilities.

We aim to acknowledge reports within 7 days.
